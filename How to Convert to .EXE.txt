HOW TO CONVERT episode_renamer.py TO A WINDOWS .EXE
=====================================================

1. Install Python 3.10+ from https://www.python.org/downloads/
   - During installation, check "Add Python to PATH"

2. Open Command Prompt and install PyInstaller:
   pip install -r requirements.txt

3. Navigate to the folder containing episode_renamer.py:
   cd path\to\episode-renamer

4. Run PyInstaller:
   python -m PyInstaller --onefile --windowed episode_renamer.py

5. Your .exe will appear in the "dist" folder:
   dist\episode_renamer.exe

6. Double-click to run. No Python installation needed on the target machine.

Notes:
- "--onefile" bundles everything into a single .exe
- "--windowed" hides the background console window (GUI only)
- To add a custom icon, use: --icon=youricon.ico
